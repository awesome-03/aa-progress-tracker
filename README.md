# TrAAcker (V1)

TrAAcker is an AA progress tracker that takes the current live [PaceMan](https://paceman.gg/aa) runs and turns them into copyable Discord messages.

The message is formatted to include important events in the run without making it a text wall.

## Other

- **IGT** is the time PaceMan has. I believe it only updates when the runner pauses or changes dimension.
- **Debris** only counts mined debris; the ones from chests aren't tracked.
- **Skulls** shows ✅ when the Wither is summoned
